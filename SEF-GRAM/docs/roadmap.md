## Веха 1: Вероятностная динамика в непрерывном времени (VJEPA + EFLA + Dirichlet)
* **Критерии завершения:** Ошибка восстановления траекторий (reconstruction MSE) на синтетическом линейно-гауссовском тесте $\le 0.05$ при длине последовательности $L=500$ с явной фиксацией падения энергии Дирихле $E(\mathcal{E}) < 0.5$.
* **Связанные риски:** 
  * [RSK-002](risks.md#rsk-002-насыщение-и-затухание-градиентов-efla) (Затухание градиентов EFLA);
  * [RSK-006](risks.md#rsk-006-численная-нестабильность-ортогонализации-ньютона-шульца-в-muon) (Нестабильность EFLA).

### Шаги реализации

#### Шаг 1.1: Кодировщик VJEPA и расчет энергии Дирихле
* **Описание:** Разработка стохастического автоэнкодера VJEPA с выводом параметров диагональной многомерной гауссианы $\mu_t, \sigma_t^2$ и интеграция расчета энергии Дирихле в логгер на этапе SFT-разминки.
* **Связанные решения:** 
  * [DEC-001](decisions.md#dec-001-представление-скрытого-состояния-gram-vjepa) (Continuous $Z_t \in \mathbb{R}^{512}$);
  * [DEC-010](decisions.md#dec-010-мониторинг-ага-момента-через-энергию-дирихле) (Мониторинг энергии Дирихле).
* **Тест:** Проверка прохождения градиентов через репараметризационный трюк в PyTorch и корректность расчета $E(\mathcal{E})$ по ходу эпох SFT.

#### Шаг 1.2: Точный переход EFLA ODE с Тейлор-стабилизацией
* **Описание:** Реализация непрерывной рекуррентной EFLA-ячейки с Taylor-аппроксимацией через `expm1` при малых значениях $\beta\lambda < 10^{-5}$ для исключения деления на ноль.
* **Связанное решение:** [DEC-002](decisions.md#dec-002-интеграция-переходов-efla-в-непрерывном-времени) (Точное уравнение EFLA ранга-1 с Тейлор-стабилизатором).
* **Тест:** Численное сравнение выхода EFLA с методом Рунге-Кутты 4-го порядка (RK-4): выходное отклонение на траекториях длины 500 должно стремиться к нулю с точностью до машинного `float32`.

## Веха 2: Поблочное масштабирование на RTX 5060 (DiffusionBlocks + EMA)
* **Критерии завершения:** Успешный запуск цикла обучения на GPU RTX 5060 при пиковом потреблении памяти $\le 4.2$ ГБ с размером батча 128 без возникновения координатного дрейфа между фазами.
* **Связанные риски:** 
  * [RSK-003](risks.md#rsk-003-cuda-out-of-memory-oom-на-целевом-gpu-rtx-5060) (CUDA OOM);
  * [RSK-005](risks.md#rsk-005-координатный-дрейф-латентного-пространства-coordinate-drift) (Координатный дрейф).

### Шаги реализации

#### Шаг 2.1: Стохастический Block Scheduling в DiffusionBlocks
* **Описание:** Написание стохастического расписания переключения активных блоков трансформера (случайный выбор блока за итерацию) для равномерного обучения параметров.
* **Связанные решения:** 
  * [DEC-003](decisions.md#dec-003-поблочное-обучение-diffusionblocks) (Поблочное обучение);
  * [DEC-008](decisions.md#dec-008-стохастическое-расписание-блоков-и-ema-coordinate-anchoring-в-diffusionblocks) (Stochastic Block Scheduling).
* **Тест:** Проверка равномерного распределения частот активации блоков на протяжении 1000 шагов обучения.

#### Шаг 2.2: EMA Coordinate Anchoring для замороженных блоков
* **Описание:** Реализация фиксации координат латентных векторов замороженных блоков трансформера через экспоненциальное скользящее среднее (EMA) с коэффициентом сглаживания $\gamma = 0.99$.
* **Связанные решения:**
  * [DEC-003](decisions.md#dec-003-поблочное-обучение-diffusionblocks) (Заморозка неактивных блоков);
  * [DEC-008](decisions.md#dec-008-стохастическое-расписание-блоков-и-ema-coordinate-anchoring-в-diffusionblocks) (EMA Coordinate Anchoring).
* **Тест:** Юнит-тест, подтверждающий отсутствие резких скачков лосса автокодирования (изменение AE Loss $< 15\%$) при смене активного блока.

## Веха 3: Turn-Based Выравнивание и Вывод (ECHO-GDPO + PoE + UNSL)
* **Критерии завершения:** Сходимость процесса обучения на OOD-лабиринтах и Sokoban с точностью правильности ответов $>95\%$ при сильном внешнем шуме (10 дистракторов) и жесткой deadlock-детекции.
* **Связанные риски:** 
  * [RSK-001](risks.md#rsk-001-коллапс-дисперсии-posterior-collapse) (Коллапс дисперсии);
  * [RSK-004](risks.md#rsk-004-запоминание-ошибок-среды-failure-mode-memorization) (Запоминание ошибок).

### Шаги реализации

#### Шаг 3.1: Объединенный гибридный лосс ECHO-GDPO
* **Описание:** Реализация гибридного лосса ECHO-GDPO на позициях токенов действий и ответов среды с коэффициентом смешивания $\lambda = 0.05$ и фильтрацией невалидных команд агента.
* **Связанные решения:**
  * [DEC-004](decisions.md#dec-004-выравнивание-без-критика-gdpo) (Групповое выравнивание);
  * [DEC-006](decisions.md#dec-006-объединенный-лосс-echo-gdpo-и-turn-based-обучение) (Гибридный лосс ECHO-GDPO).
* **Тест:** Сравнение гранулированности векторов преимуществ и проверка обучения модели мира на проваленных траекториях по лоссу $\mathcal{L}_{Env}$.

#### Шаг 3.2: Планировщик BJEPA PoE с Gram-Muon и UNSL автонастройкой
* **Описание:** Создание планировщика Product of Experts с 100% латентной deadlock-детекцией и автонастройкой шагов размышлений $T$ по уравнениям UNSL, а также интеграция оптимизатора Gram-Muon для экономии FLOPs.
* **Связанные решения:**
  * [DEC-001](decisions.md#dec-001-представление-скрытого-состояния-gram-vjepa) (Байесовское слияние);
  * [DEC-005](decisions.md#dec-005-оптимизация-скрытых-слоев-через-muon) (MuonWithAuxAdam);
  * [DEC-007](decisions.md#dec-007-оптимизация-шага-muon-через-gram-матрицы) (Gram-Muon ортогонализация);
  * [DEC-009](decisions.md#dec-009-интеграция-unsl-unified-neural-scaling-laws) (Inference-Time Scaling UNSL).
* **Тест:** Достижение цели на OOD-тестах за оптимальное число шагов $T$ по кривым масштабирования.
