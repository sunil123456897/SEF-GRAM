## Общие сведения о модели
Модель **ECHO-GRAM** (Error-Free Generative Recursive Reasoning Model with Turn-Based Adaptation) представляет собой SOTA-архитектуру, совмещающую непрерывные вероятностные модели мира (VJEPA), высокоточные переходы в непрерывном времени (EFLA ODE), байесовское латентное планирование (PoE) и гибридное RL-выравнивание (ECHO-GDPO). Модель спроектирована под жесткие ограничения видеокарты **NVIDIA RTX 5060 (8 ГБ VRAM)**.

---

## Архитектурные характеристики

* **Тип архитектуры:** Единая унифицированная Transformer-Backbone модель (Weight-Sharing Policy + World Model). 
* **Размерность латентного пространства:** $D = 512$.
* **Метод представления состояний:** Стохастическая многомерная гауссиана с диагональной ковариационной матрицей:
  $$Z_t \sim \mathcal{N}(\mu_t, \sigma_t^2 I)$$
* **Динамическое ядро:** Непрерывный ODE-решатель EFLA (Error-Free Linear Attention) ранга-1 с численной Тейлор-стабилизацией при малых значениях $\beta\lambda < 10^{-5}$ через встроенную функцию `expm1`.
* **Метод вывода при инференсе (Планирование):** Аналитический байесовский фильтр в скрытом пространстве (Bayesian Latent Filtering) с использованием произведения экспертов (**Product of Experts - PoE**) для поиска траектории к цели без декодирования пикселей или посимвольного рендеринга текста.
* **Inference-Time Scaling (UNSL):** Автоматический расчет оптимального числа шагов размышлений $T$ на инференсе по кривым Unified Neural Scaling Laws для минимизации вычислительных затрат при сохранении целевой точности $>95\%$.

## Характеристики оптимизатора и процесса обучения

Для обучения на целевом оборудовании используется гибридный оптимизатор **`MuonWithAuxAdam`** с Gram-ортогонализацией весов и гибридный лосс **`ECHO-GDPO`**:

### Оптимизатор Muon с Gram-ортогонализацией
* **Группа 1 (Скрытые 2D весовые матрицы):** **Muon** (Momentum Orthogonalized by Newton-Schulz) со следующими параметрами:
  $$\text{lr} = 0.02, \quad \text{momentum} = 0.95, \quad \text{ns\_steps} = 5$$
  Вычисление полярного разложения Ньютона-Шульца производится через компактную матрицу Грама $R = X X^\top$ размером $n \times n$ (где $n \ll m$), что снижает нагрузку на GPU (FLOPs) на 50%.
* **Группа 2 (1D параметры, эмбеддинги, головы):** **AdamW** (Auxiliary Adam) с $\text{lr} = 3 \times 10^{-4}, \; \beta_1 = 0.9, \; \beta_2 = 0.95$, сильная регуляризация **Weight Decay** = $0.05$ (для жесткого MDL-сжатия по Соломонову).

### Гибридный лосс ECHO-GDPO
* Объединяет лосс GDPO на токенах действий с лоссом предсказания среды на токенах ответа терминала ($\mathcal{L}_{Env}$) с коэффициентом смешивания $\lambda = 0.05$ в рамках одного прохода:
  $$\mathcal{L}_{ECHO-GDPO}(\theta) = \mathcal{L}_{GDPO}(\theta; A) + \lambda \mathcal{L}_{Env}(\theta; O')$$
* **Предотвращение дрейфа:** В блоке **DiffusionBlocks** применяется стохастическое расписание блоков (Stochastic Block Scheduling) и фиксация геометрии скрытых векторов через экспоненциальное скользящее среднее (EMA Coordinate Anchoring) с коэффициентом сглаживания $\gamma = 0.99$.
* **Мониторинг "Ага!-момента":** Многомерная энергия Дирихле $E(\mathcal{E})$ в скрытом пространстве рассчитывается на этапе SFT. Резкое падение энергии сигнализирует об успешном формировании реляционных инвариантов и запускает Early Stopping перед фазой RL.

## Аппаратные требования и оптимизация VRAM

* **Целевой GPU:** **NVIDIA RTX 5060 (8 ГБ VRAM)**.
* **Системная память (RAM):** $\ge 32$ ГБ.
* **Целевой показатель потребления VRAM:** $\le \mathbf{4.2}$ ГБ (пиковое). Снижено на 1.5 ГБ за счет weight-sharing Policy + World Model в рамках единого Backbone.
* **Решения по оптимизации памяти:**
  1. Поблочное обучение **DiffusionBlocks** (3 блока по 4 слоя) позволяет вычислять градиенты только для 1/3 модели за итерацию, высвобождая память под большие батчи ($N=128$).
  2. Использование оптимизатора **Muon** вместо AdamW для тяжелых 2D-весов устраняет необходимость хранить 4 байта на параметр под вторые моменты градиентов.
  3. Аппаратное ускорение внимания **FlashAttention-2** для минимизации квадратичной сложности по памяти на длинных контекстах.
  4. Точность весов **fp16/bf16** используется как индуктивное смещение (MDL-сжатие) и для экономии VRAM.
